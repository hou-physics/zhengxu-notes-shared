step1_uvcontsub.py (Scenario A only)

UV-plane continuum subtraction in CASA, used only when re-imaging from visibility data (Scenario A). For all 32 sources in the final sample the pipeline-imaged FITS product was used directly (Scenario B), so this script was not run; it is preserved as the reference for the two cases (NGC 4418, NGC 1097) where re-imaging was considered.

Line-free channel windows are tabulated explicitly per SPW. The fitorder = 1 degree-1 polynomial baseline matches the rest of the pipeline.

##############################################################################
# Step 1: UV Plane Continuum Subtraction (CASA 6.6)
#
# Usage: run inside CASA 6.6
#   cd to the manual_calibration directory
#   casa --nologger --nogui
#   execfile('step1_uvcontsub.py')
#
# Note: CASA 6.6's uvcontsub is the new API:
#   - parameter name: fitspec (not fitspw)
#   - outputvis must be specified (no automatic .contsub naming)
#   - does NOT support: combine, want_cont, solint
#   - for the old behaviour, use uvcontsub_old
##############################################################################

import os

vis = 'NGC3628_concatenated.ms'
outputvis = 'NGC3628_concatenated.ms.contsub'

if not os.path.exists(vis):
    print("ERROR: {} not found!".format(vis))
    import sys; sys.exit(1)

print("="*70)
print("  Step 1: UV Plane Continuum Subtraction (CASA 6.6)")
print("="*70)
print("")

# ---- listobs ----
print("--- running listobs ---")
listobs(vis=vis, listfile='NGC3628_listobs_check.txt', overwrite=True)
print("saved to NGC3628_listobs_check.txt")
print("")

# ---- clean up previous output ----
if os.path.exists(outputvis):
    print("removing previous {} ...".format(outputvis))
    os.system('rm -rf ' + outputvis)

# ============================================================================
# fitspec parameter
#
# CASA 6.6 uvcontsub uses fitspec in place of the legacy fitspw.
# Same syntax: 'spw:frequency-range' or 'spw:channel-range'.
#
# SPW configuration for NGC 3628:
#   SPW 0/4: ~228.44–230.30 GHz, contains CO(2-1) near ~229.90 GHz
#   SPW 1/5: ~230.81–232.69 GHz, contains H30α near ~231.26 GHz
#
# Strategy: pick line-free channels for the continuum fit
#   SPW 0: 228.49–229.55 GHz (left of CO, excluding SPW edges and CO)
#   SPW 1: 230.86–231.00 GHz; 231.55–232.64 GHz (either side of H30α)
#   SPW 4: same as SPW 0
#   SPW 5: same as SPW 1
#
# Always check NGC3628_listobs_check.txt for the actual SPW frequency
# ranges before running; adjust the values below if they differ.
# ============================================================================

fitspec_str = (
    '0:228.49~229.55GHz,'
    '1:230.86~231.00GHz;231.55~232.64GHz,'
    '4:228.49~229.55GHz,'
    '5:230.86~231.00GHz;231.55~232.64GHz'
)

print("fitspec = '{}'".format(fitspec_str))
print("fitorder = 1")
print("outputvis = '{}'".format(outputvis))
print("")
print("starting uvcontsub ... (typically 20-40 minutes)")
print("")

uvcontsub(
    vis       = vis,
    outputvis = outputvis,
    field     = 'NGC_3628',
    spw       = '0,1,4,5',
    fitspec   = fitspec_str,
    fitorder  = 1
)

print("")
if os.path.exists(outputvis):
    print("uvcontsub finished. Output: {}".format(outputvis))
    listobs(vis=outputvis, listfile='NGC3628_contsub_listobs.txt', overwrite=True)
    print("listobs saved")
else:
    print("ERROR: output file was not created!")

print("")
print("="*70)
print("Next steps:")
print("  1. Inspect quality with plotms (in CASA GUI):")
print("     plotms(vis='{}',".format(outputvis))
print("            xaxis='frequency', yaxis='amplitude',")
print("            avgtime='1e8', avgscan=True, field='NGC_3628')")
print("  2. Confirm line-free regions are near zero, CO is clear, and")
print("     the H30α neighbourhood is clean.")
print("  3. Run step2_imaging.py")
print("="*70)
